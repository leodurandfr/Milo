# Milo Client - what the satellite app imports, as floors.

# The input of requirements.lock beside it, never installed as it stands: the
# image and every app update install the lock, with --require-hashes. After any
# edit here, compile the lock again from this directory (its header names the
# command), against the server's lock so a package both apps use is pinned at
# the version CI tests them with — one venv runs both suites.
#
# An app update copies the venv aside and runs pip only when the lock differs
# from the one the unit runs, byte for byte: a comment edited here costs no
# satellite anything, a lock compiled again costs each one a venv copy and a
# pip run on its next push.
